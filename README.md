# Джарвис — голосовые мысли

Приложение для Android записывает голос, сохраняет аудио на телефоне и отправляет его на ваш компьютер. Сервер распознаёт русский язык и сохраняет заметку в Markdown. При подключённом OpenAI API он также составляет конспект и выделяет задачи.

**Сейчас ключ AI не задан.** По умолчанию работает локальное распознавание Whisper; заметки получают статус «Расшифровано · ожидает AI». Это настоящий текст из аудио, но ещё не AI-конспект. Подключение AI описано ниже. Тестовые провайдеры используются только при проверках и помечают результаты как тестовые.

## Первый запуск на этом компьютере

1. Откройте папку проекта `джарвисенок мой` в «Загрузках».
2. Если установка ещё не выполнена, дважды нажмите **setup.bat**. Нужен интернет для установки библиотек. Python 3.12 или новее должен быть установлен; на этом ПК уже есть Python 3.13.
3. Дважды нажмите **start.bat**. Сервер запускается в фоне.
4. Откройте [панель заметок](http://127.0.0.1:8765/).
5. Откройте файл **data → connection.txt**, скопируйте токен и вставьте его в панель.

Для остановки дважды нажмите **stop.bat**. Принятые записи сохраняются; прерванная обработка продолжится после следующего запуска. Автозапуск Windows по умолчанию выключен.

## Подключить Android

1. Скопируйте **dist → jarvis-debug.apk** на телефон через USB или удобным вам способом.
2. Откройте APK на телефоне. Если Android попросит, разрешите установку из этого источника. Это тестовая локальная сборка для личного использования, не публикация в магазине.
3. Подключите телефон к той же Wi-Fi сети, что и ПК.
4. Откройте «Джарвис → Подключение и микрофон».
5. В **data → connection.txt** на компьютере найдите адрес вида `http://192.168.…:8765`. Введите его в приложение. Адрес `127.0.0.1` на телефоне не подходит.
6. Скопируйте токен из того же файла. Нажмите «Сохранить».
7. Разрешите микрофон. Для гарнитуры разрешите «Устройства поблизости», для уведомления — уведомления.
8. Если Windows спросит доступ к сети для Python, разрешите **частную домашнюю сеть**.

Приложение рассчитано на Android 8.0 и новее. Проверка микрофона и Bluetooth на вашем физическом телефоне обязательна: поведение производителей различается.

## Первая мысль

Нажмите **«Записать мысль»**, говорите, затем **«Остановить запись»**. Для начала попробуйте: «Завтра надо позвонить поставщику роллштор до двенадцати. Возможно цена около пятнадцати тысяч».

Аудио сразу сохраняется на телефоне. Если ПК недоступен, запись остаётся в очереди. После отправки приложение показывает состояние обработки. Если автоматические повторы исчерпаны, нажмите **«Отправить / обновить»**. Если ошибка возникла на сервере, откройте запись в панели и нажмите **«Повторить обработку»** после исправления причины.

Готовые заметки появляются в **notes → год → месяц → день**. Имя включает время и уникальный ID, поэтому правка заголовка не создаёт дубликат. Эту папку можно открыть как хранилище Obsidian. Конспект и задачи также отображаются в записи на телефоне после обновления статуса.

## Подключить AI позже

1. Остановите сервер через **stop.bat**.
2. Откройте **.env** в папке проекта в Блокноте. Если файл не виден, включите показ скрытых файлов в Проводнике.
3. После `OPENAI_API_KEY=` вставьте ваш API-ключ.
4. Замените `LLM_PROVIDER=pending` на `LLM_PROVIDER=openai`.
5. После `OPENAI_LLM_MODEL=` укажите доступную вашему API-аккаунту модель с поддержкой Responses API и Structured Outputs. Модель не выбрана автоматически, чтобы не навязывать расход средств.
6. Сохраните файл и запустите **start.bat**.
7. В панели откройте нужную старую запись и нажмите **«Повторить обработку»**. Исходная расшифровка останется прежней.

Это интеграция через OpenAI API. Ключ не нужно вставлять в Android. Программа не выполняет платные запросы, пока вы не включите провайдера. Для облачного распознавания дополнительно задайте `STT_PROVIDER=openai`; локальное распознавание можно оставить.

## Полезное

- Панель: [http://127.0.0.1:8765/](http://127.0.0.1:8765/).
- API-документация: [http://127.0.0.1:8765/docs](http://127.0.0.1:8765/docs).
- Логи этапов: **data/logs/backend.jsonl**, до пяти файлов по 2 МБ.
- Ошибки запуска: **data/startup.err.log**.
- Быстрый запуск: удерживайте иконку приложения; добавьте виджет или плитку «Записать мысль» в шторку.
- Автоостановка по тишине отключена по умолчанию; её можно включить в настройках, но обязательно проверить в своём окружении.
- Аудио хранится по умолчанию без автоудаления. Контролируйте свободное место: минута — около 1.9 МБ.
- Для резервной копии остановите сервер и скопируйте **data**, **notes** и **.env** на свой резервный носитель. Файлы содержат личные данные и секрет подключения.
