# Использованные первичные источники

Проверены при разработке 8–9 сентября 2026.

- Android foreground service microphone и разрешения: https://developer.android.com/develop/background-work/services/fgs/service-types
- Bluetooth communication device: https://developer.android.com/develop/connectivity/bluetooth/ble-audio/audio-manager
- AGP 8.9.2, совместимость Gradle 8.11.1 / SDK 35: https://developer.android.com/build/releases/agp-8-9-0-release-notes
- Android SDK command-line tools: https://developer.android.com/studio
- faster-whisper: https://github.com/SYSTRAN/faster-whisper
- OpenAI Structured Outputs: https://developers.openai.com/api/docs/guides/structured-outputs
- OpenAI transcription: https://developers.openai.com/api/docs/guides/speech-to-text
