# Обновление 0.3.0

Android: кодовое слово «Пятница», тишина 1–10 секунд (по умолчанию 2), вибрация, пауза автоотправки, удаление ещё не отправленных записей, прослушивание и просмотр/отмена действий.

Obsidian: главная страница, читаемые имена, темы в тегах, строгий отбор людей, единые страницы финансов и отдельный журнал поручений.

Сервер: расходы, доходы, долги, Google Calendar OAuth, импорт аудиофайлов. Настройки и учётные данные создаются локально. Запуск вручную через start.bat, остановка через stop.bat.

Проверки: 34 backend-теста, Android unit tests и lint. Проверка на реальном Android требуется после установки. Версия для личного прототипа, не готовый многопользовательский сервис.

APK устанавливается поверх предыдущей версии только при совместимой подписи. Не удаляйте приложение, пока локальные записи не сохранены. Секреты, записи и база данных в репозиторий не включены.
