# Пятница 0.5.0 — диалог и выполнение поручений

## Установка на текущем компьютере и телефоне

1. После включения ПК запустите `start.bat` из папки проекта. Автозапуск Windows не создаётся.
2. Установите APK 0.5.0 поверх прежней версии, не удаляя приложение: записи и подключение сохранятся.
3. Откройте «Диалог с Пятницей». Пишите поручение или используйте кнопку «Голосом» / слово «Пятница».
4. Продолжайте задачу сообщениями в том же диалоге. Кнопка «Новый диалог» создаёт отдельную историю.
5. Для мобильного интернета оставьте включённым Tailscale на ПК и телефоне.
6. Google отклонил обновление прежнего разрешения (`invalid_grant`): на ПК нажмите «Подключить Google Календарь» и войдите повторно. Программа теперь явно показывает это состояние. До входа новые встречи не будут созданы.

Windows-установщик предназначен для отдельной установки с собственным каталогом данных. На этом ПК проект уже обновлён; для сохранения текущих заметок и настроек продолжайте запуск через `start.bat`. Установщик автоматически личные данные исходного проекта не переносит.

## Как работает помощник

Модель получает цель и сама выбирает инструменты через Responses API. Результаты возвращаются модели, она уточняет план и продолжает работу. Отдельного сценария для каждого вида поручений нет.

Доступны история диалога, веб-поиск со ссылками, местные услуги и поставщики, память предпочтений, чтение прежних заметок, сохранение результатов в Obsidian, калькулятор, бюджет, расходы, доходы, долги, чтение календаря и предложения встреч. Геолокация передаётся только по кнопке с разрешением Android; иначе Караганда используется как домашний город, а не точная позиция.

На телефоне есть прикрепление PDF, DOCX, XLSX, PPTX, TXT, MD, CSV до 20 МБ. Сначала введите поручение, затем выберите файл. Файлы сохраняются на ПК; MarkItDown извлекает текст для модели. Поддержка сложной вёрстки и сканов не гарантируется.

Финансовые суммы хранятся в целых тиынах. Карточки операций и остаток берутся из базы независимо от текста ответа модели. Во время проверки обнаружена и исправлена ошибка представления единиц в ответе; текстовые выводы ИИ всё равно требуют проверки, особенно в важных решениях.

## Надёжность и ограничения

- Сообщение сохраняется на телефоне до подтверждения приёма ПК. При потере ответа используется тот же идентификатор, без создания второго задания.
- Шаги и вызовы инструментов хранятся в отдельной `assistant.sqlite3`. Прерванные задания восстанавливаются после ручного запуска сервера.
- Повтор одного вызова и повтор идентичного финансового намерения в том же сообщении не создают вторую операцию. Семантическое понимание разных формулировок остаётся задачей модели.
- Создание встречи и отмена требуют кнопочного подтверждения. Отмена задачи останавливает дальнейшие шаги, но не откатывает ранее выполненные операции автоматически.
- По умолчанию за проход допускается 12 обращений к модели; затем доступно «Продолжить». Это ограничение расходов, а не обещание бесконечного бесплатного исполнения.
- Сторонний агент ограничен четырьмя минутами и прекращается вместе с сервером. Веб-страницы и отчёты других агентов являются недоверенными данными.
- Банк, телефонные звонки, реальные бронирования в салонах и отправка писем не подключены. Модель обязана сообщать об отсутствии инструмента, а не имитировать выполнение.
- Статистика API основного приложения не включает все внутренние обращения сторонних агентов и эмбеддингов. Полный счёт смотрите у провайдера.
- История на сервере сохраняется; интерфейс загружает последние 60 сообщений, в текущий контекст модели включаются последние 20 сообщений и сохранённые факты. Бесконечной памяти модели нет.
- На реальном телефоне ещё нужно проверить микрофон, геолокацию, установку поверх старой версии и работу при заблокированном экране.

## Настройки

`OPENAI_AGENT_MODEL` позволяет отдельно выбрать модель помощника. Если пусто, используется прежняя `OPENAI_LLM_MODEL`; текущий пользовательский выбор автоматически не меняется. Настройка размышления в Codex не меняет модель Android-помощника.

`ASSISTANT_MAX_STEPS`, `ASSISTANT_CITY`, `ASSISTANT_WEB_SEARCH`, `AGENTS_PYTHON` задаются в `.env` на ПК. Постоянные токены и API-ключи не публикуются.

До изменений сделана резервная копия базы и исходников в `data/backups/assistant-*`. Тесты выполняются в отдельных каталогах и не меняют личный бюджет.

Технические источники: [Responses function calling](https://developers.openai.com/api/docs/guides/function-calling), [Web search](https://developers.openai.com/api/docs/guides/tools-web-search). Репозитории компонентов перечислены в `ROADMAP.md`.

## Проверка сборки

Пройден 51 тест backend, 6 модульных тестов Android и lint. Проверены реальные вызовы OpenAI: веб-поиск со ссылкой, расход и прогноз без повторного списания, сохранение предпочтения. Отдельно проверены Browser Use, GPT Researcher, Mem0 и MarkItDown. Windows-установка, запуск установленного приложения с API-проверкой и удаление прошли успешно. Личный бюджет до и после обновления совпал; личные ключи не найдены в публикуемых исходниках. Проверка на физическом телефоне остаётся обязательной.
