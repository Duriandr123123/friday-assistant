# Android

Kotlin, Android SDK 35, minSdk 26, AGP 8.9.2, Gradle 8.11.1, Java 17 bytecode. UI — нативные Android Views, фоновые задания — WorkManager 2.10.1. Android Studio для ежедневной работы не нужна.

## Сборка

На этом ПК подготовлены SDK и Gradle в .tools; запуск:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build-android.ps1
```

Скрипт собирает debug APK, запускает unit tests и lint, копирует APK в dist/jarvis-debug.apk. На другом ПК установите Android SDK и JDK 17+; для скрипта задайте ANDROID_HOME и JAVA_HOME. При ручном запуске Gradle можно указать SDK в android/local.properties. Gradle Wrapper скачивает закреплённый Gradle при первом запуске и проверяет SHA-256.

Для обхода ошибки Windows/JVM с кириллицей в пути скрипт копирует исходники сборки в `%LOCALAPPDATA%\JarvisThoughtsBuild\android`. Рабочий проект остаётся в исходной папке; служебная копия не содержит .env и пользовательских заметок.

Это debug APK для проверки на личном телефоне. Для продажи нужны собственный постоянный release-ключ, подписанная release-сборка, политика приватности и испытания устройств; debug-подпись для этого не подходит.

## Ручная проверка на телефоне

1. Записать 20 секунд без гарнитуры; открыть запись и прослушать. Проверить расшифровку на ПК.
2. Подключить гарнитуру; повторить и проверить фактический источник звука. Разрешить nearby devices.
3. Во время записи выключить Bluetooth: проверить продолжение или сохранение доступного фрагмента.
4. Записать с выключенным Wi-Fi; закрыть приложение, включить сеть, открыть и нажать «Отправить / обновить». Не должно быть двух заметок.
5. Начать запись и погасить экран; остановить через уведомление.
6. Перезапустить телефон после завершённой записи без сети. Проверить наличие файла и доставку.
7. Принудительно остановить приложение во время записи, затем открыть. Доступное PCM-аудио должно восстановиться.
8. Остановить backend во время обработки, запустить снова и проверить завершение записи.

Не утверждаем, что эти аппаратные сценарии проверены до выполнения на вашем устройстве. Unit-тест WAV проверяет восстановление заголовка, но не поведение прошивки телефона.

## Ограничения

При обычном сворачивании работает foreground service с уведомлением. Нельзя гарантировать запись при force-stop, отзыве разрешений, полном диске, неисправности устройства или вмешательстве прошивки. После принудительной остановки снова откройте приложение для восстановления. Аудио в приватном каталоге приложения: удаление приложения удалит локальные копии.

Автоостановка по амплитуде отключена по умолчанию и обозначена экспериментальной. Ограничение записи — 10 минут. Bluetooth Android 12+ выбирается через setCommunicationDevice, старые версии через SCO. При ошибке чтения есть одна попытка переключения на телефон; фрагмент не удаляется.

## Быстрые способы

Удержание иконки → «Записать мысль». Виджет на рабочем столе. Плитка в шторке. Эти способы открывают Activity, чтобы получить разрешённый запуск микрофона. Уведомление активной записи содержит кнопку остановки.

Wake word и Bluetooth media button пока отложены: постоянное прослушивание и перехват кнопок требуют отдельной проверки батареи, фоновых ограничений и совместимости. Наушники не обязаны поддерживать запуск произвольного приложения своей кнопкой.
