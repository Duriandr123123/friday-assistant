# Проверка 9 сентября 2026

## Android 0.2.0

Добавлены кодовое слово «Сюзанна» и ручной переключатель фонового прослушивания. Сборка assembleDebug и lintDebug прошли; 6 unit-тестов (2 прежних и 4 проверки совпадений/стабильности ключевого слова) прошли. Словарь реальной модели ru-0.22 проверен через Vosk: оба написания имени присутствуют. Это проверка словаря и логики, не измерение распознавания голоса пользователя. Синтетическое английское произношение имени не распозналось как русское целевое слово; для итоговой оценки нужна русская речь на телефоне.

Подключённого Android нет. Ожидание на погашенном экране, переключения микрофона, точность wake word и расход батареи пока не проверены аппаратно. Автозапуск Windows не включался; после прерывания питания продолжена только ручная сборка.

Android unit-тесты не заменяют испытания микрофона и Bluetooth. Физический Android не был подключён. Список ручных сценариев — ANDROID.md. APK предназначен для следующего шага испытаний на устройстве пользователя.

Серверные проверки отдельно покрывают: конфликты UUID, повреждённое аудио, отсутствие авторизации, ограничение размера/текста, исчерпание повторов, неповторяемые ошибки, сохранение транскрипта при сбое AI, сохранение AI checkpoint при ошибке Markdown, повторный старт, правки без замены raw transcript и удаление файлов/FTS.

В testclient остаются два предупреждения об устаревающих внутренних API Starlette/AnyIO; тесты проходят. Версии установленных библиотек закреплены в requirements.lock.txt.
