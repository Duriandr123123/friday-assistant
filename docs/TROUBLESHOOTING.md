# Если что-то не работает

| Симптом | Действие |
|---|---|
| Панель не открывается | Запустите start.bat; проверьте data/startup.err.log |
| Неверный токен | Возьмите токен из data/connection.txt, без пробелов и переносов |
| Телефон не видит ПК | Проверьте общую сеть, IP, частный профиль firewall; не используйте 127.0.0.1 на телефоне |
| Расшифровка долго обрабатывается впервые | Модель скачивается; нужен интернет. Состояние видно в панели |
| local_stt_not_installed | Повторите setup.bat |
| speech_not_detected | Прослушайте аудио; выберите микрофон телефона и сделайте новую запись |
| awaiting_ai | Это ожидаемо без ключа: подключите AI по README и нажмите повторную обработку |
| api_key_missing / llm_model_missing | Заполните .env и перезапустите backend |
| provider_http_401 | Ключ сервиса недействителен; обновите локально в .env |
| provider_http_429 | Ограничение сервиса; проверьте аккаунт/лимиты, затем повторите |
| invalid_ai_schema / unsupported_task_evidence | Ответ AI не прошёл проверку; аудио и транскрипт сохранены, повторите обработку |
| needs_attention на Android | Автоповторы закончились; проверьте подключение и нажмите «Отправить / обновить» |
| server_error на Android | Исправьте причину на ПК и нажмите «Повторить обработку» в панели, затем обновите Android |
| processing_internal_error | Проверьте свободное место, доступность модели/папок; перезапустите сервер и повторите |
| Гарнитура не записывает | Разрешите nearby devices; выключите использование гарнитуры в настройках и проверьте телефон |

Основной журнал: data/logs/backend.jsonl. В нём время, код этапа и ID записи; содержимое речи и секреты не журналируются. Файлы startup.*.log перезаписываются при запуске.

Не удаляйте data и приложение ради «сброса»: там сохранённые записи. Перед переносом или обновлением остановите сервер и сделайте копию data, notes, .env. Если редактируете модель или токен — перезапустите сервер.
