# Сюзанна: Obsidian, бюджет, долги и календарь

После загрузки записи сервер делает расшифровку и конспект, записывает Markdown в настроенную NOTES_DIRECTORY, затем выполняет распознанные поручения. Для текущего ПК это папка «Сюзанна» внутри существующего Obsidian Vault. Obsidian не обязательно держать открытым.

## Связи
Конспекты сохраняются по дате, с устойчивым именем по ID записи. Отдельные страницы объединяют людей, проекты, компании, темы и дни. Используйте обратные ссылки и локальный граф Obsidian. Страницы сущностей можно дополнять вручную: повторная выгрузка их не перезаписывает. Разные имена и сокращения не объединяются автоматически. Конспекты являются экспортом приложения: повторная обработка обновляет их.

## Финансы
В панели откройте «Финансы и поручения» и задайте начальный общий бюджет в тенге. Это исходная сумма до всех внесённых операций, а не желаемый текущий остаток. Пока сумма не задана, операции с движением денег ожидают настройки. Учёт не выполняет банковских переводов.

Расходы и доходы меняют остаток; долги ведутся отдельно по направлениям «Я должен» / «Мне должны». Фиксация существующего долга без передачи денег не меняет остаток. Частичное погашение уменьшает единственный подходящий долг; неоднозначные случаи требуют уточнения в панели. Сумма погашения не может превышать остаток. Перед отменой долга нужно отменить его погашения.

Итоги автоматически выгружаются в «Финансы/Бюджет — автоматически.md» и «Финансы/Долги — автоматически.md». Редактирование этих сводок не изменяет базу, они пересоздаются. Старые страницы «Бюджет» и «Долги» можно использовать для собственных пояснений.

Повторный импорт одного и того же файла и повторная обработка записи не повторяют её действия. Уже созданный план действий не заменяется при редактировании расшифровки: отмените неправильное действие и создайте новое поручение. Новый отдельный файл с повторно произнесённой командой является новым поручением.

## Подключение Google Календаря — требуется владелец аккаунта
1. В Google Cloud включите Google Calendar API для своего проекта.
2. Настройте OAuth consent screen и добавьте свой аккаунт в test users, если приложение в режиме тестирования.
3. Создайте OAuth client ID типа Desktop app, скачайте JSON.
4. На самом ПК откройте нашу панель, раздел «Финансы и поручения» → «Загрузить OAuth JSON Google».
5. Нажмите «Подключить Google Календарь», войдите в свой Google-аккаунт и предоставьте доступ. Секреты не нужно отправлять в чат.
6. Обновите поручения. Доступ проверяется при реальном запросе; наличие токена не гарантирует, что разрешение не отозвано.

Используется основной календарь и доступ calendar.events.owned. По умолчанию встреча длится 60 минут, напоминание за 30 минут; можно назвать другие значения в поручении. При недоступном Google очередь повторяется. События получают стабильный ID для защиты от дублей. При неоднозначном времени и прошедшей дате требуется уточнение. Гости не приглашаются, письма не отправляются.

OAuth JSON и токен хранятся локально в data, вне Obsidian и Git; не пересылайте папку data другим людям. Для коммерческого распространения потребуется собственная настройка OAuth и проверка условий Google. Реальное подключение аккаунта в этой сессии не выполнено.

## Мобильный интернет
Android уже допускает адреса Tailscale 100.64.0.0/10 и работает при любой подключённой сети, не только Wi-Fi. После самостоятельной настройки Tailscale введите его IPv4-адрес ПК с портом 8765 в Android-приложении. Токен тот же. Проверка: отключить Wi-Fi телефона, включить Tailscale, отправить короткую запись и дождаться заметки в Obsidian. Это ещё не проверено на реальном телефоне.

ПК должен быть включён и сервер запущен вручную через start.bat. stop.bat останавливает сервер. Автозапуск Windows для проекта не добавляется. Установка Tailscale выполнена, дальнейшая настройка остановлена по просьбе пользователя.

## Импорт с диктофона
В панели кнопка «Импорт с диктофона»: WAV, MP3, M4A, OGG/FLAC, до 60 минут и 256 МБ на файл. Длинные файлы разделяются на несколько записей до 10 минут: они обрабатываются отдельно. Дата берётся из времени изменения файла; часы дешёвого диктофона могут быть неверны. Исходный файл на устройстве сохраняется.
