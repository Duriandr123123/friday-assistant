# Пятница 0.4.0

## Для нового пользователя

1. Установите Friday-Setup-0.4.0.exe и откройте «Пятница» с рабочего стола.
2. Введите собственный OpenAI API-ключ, доступную вашему аккаунту модель обработки и папку заметок. Обработка платная по условиям вашего API-аккаунта. Установщик использует облачное распознавание; Python отдельно не требуется.
3. Нажмите «Запустить», затем «Скопировать токен» и «Открыть панель». Вставьте токен в панель.
4. В панели раскройте «Подключить телефон», выберите адрес компьютера и создайте QR. Код одноразовый, действует две минуты.
5. Установите APK на телефон. Нажмите «Сканировать QR подключения» и подтвердите адрес. Кнопка «Проверить связь» проверяет сервер и токен.

В домашней сети используйте адрес Wi-Fi/Ethernet. Через мобильную сеть нужен Tailscale на обоих устройствах и адрес Tailscale. Компьютер и сервер должны быть включены. Правила брандмауэра зависят от настройки Windows; установка не открывает порты автоматически.

## Для текущего пользователя проекта

APK устанавливается поверх версии 0.3.0. Ваш существующий сервер запускается как раньше через start.bat. Установщик создаёт отдельную конфигурацию и сам не переносит прежнюю базу или ключи; одновременно два сервера на порту 8765 не запускайте.

## Изменения

- Одноразовое QR-подключение и проверка связи.
- Уточнение суммы, человека, направления долга и даты встречи на телефоне. Уже выполненные действия сначала отменяются.
- Статистика запросов, токенов, кэша и минут облачного распознавания. Тарифы задаются пользователем в панели; сумма является оценкой, не счётом OpenAI. Неопределённые запросы могут быть оплачены. История до обновления не восстанавливается.
- Дополнительные проверки восстановления после сбоя без повторного списания.
- Windows-приложение запускается вручную; закрытие окна останавливает его сервер. Автозапуск и фоновые службы проекта не устанавливаются. Пользовательские данные остаются в LocalAppData/FridayAssistant/UserData при удалении программы.

## Проверки и ограничения

37 backend-тестов, Android unit tests и lint. Проверены установка Windows-пакета, запуск установленного приложения с временной базой и удаление. Проверка настоящей камеры QR, микрофона, сети и батареи требует телефона. Установщик не подписан коммерческим сертификатом. Google Calendar требует отдельной OAuth-настройки владельца; эта версия не решает публикацию общего Google OAuth-приложения для всех покупателей.

Сборка Windows: установите PyInstaller в окружение проекта и NSIS, затем scripts/build-desktop.ps1. Сборка Android: scripts/build-android.ps1. Секреты и пользовательские данные не входят в пакеты.

Документация компонентов: [QR-сканер](https://github.com/journeyapps/zxing-android-embedded), [NSIS](https://nsis.sourceforge.io/Docs/AppendixI.html).
